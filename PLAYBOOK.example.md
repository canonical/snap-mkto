# Playbook (example)

Copy this file to your mkto config directory as `playbook.md` and edit it:

- snap: `~/snap/mkto/common/playbook.md`
- from source: `~/.config/mkto/playbook.md`

The real `playbook.md` is never committed and never built into the snap. `mkto brief` uses it as the only source of what Canonical can offer, so the model can only recommend what's written here.

## Rules for the pitch

- Recommend at most 3 offerings.
- Tie every recommendation to a specific event or research source.
- If nothing fits, say so instead of stretching.
- No pricing, discounts or commitments.
- Tone: helpful and specific, not salesy.
